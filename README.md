# Labrador_Sea_microbial_communities

Processing of amplicon data (16S V4V5) from CTD samples collected during AZOMP19, AZOMP22, BELAS-1 and BELAS-2.

**BLAST cp16S and 18S euk ASVs for additional taxonomy**

BLAST_code: code to extract sequences and find current taxonomy for manual correction

BLAST_files: original fasta files from Fuhrman pipeline

BLAST_output: alignment output from 2 separate BLAST runs; top 20 compiled with and without BLAST alignment taxonomy adjustments
